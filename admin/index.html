Administration du portfolio

Le contenu est modifié avec Pages CMS. La connexion et le droit d’enregistrer des changements sont contrôlés par GitHub.

Se connecter avec GitHub ↗ Retour au portfolio
  1. Connectez-vous avec le compte GitHub qui possède le dépôt.
  2. Sélectionnez le dépôt du portfolio, puis « Contenu du portfolio ».
  3. Ouvrez une rubrique, ajoutez ou réordonnez ses blocs, puis enregistrez.
  4. Pour un CV, un mémoire ou un support, choisissez un fichier PDF : il sera déposé dans le dépôt et affiché dans le lecteur du site.

Sécurité : cette page d’entrée est publiquement visible, mais elle ne contient ni mot de passe ni secret. Seul un compte disposant d’un droit d’écriture sur le dépôt GitHub peut modifier et enregistrer le contenu.
